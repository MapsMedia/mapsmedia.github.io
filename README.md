# M. Seema — Awwwards-inspired Developer Portfolio

A high-end, dependency-free HTML/CSS/JavaScript portfolio designed for GitHub Pages and Netlify.

## Files

- `index.html` — portfolio structure/content
- `styles.css` — visual system, responsive layout and animations
- `script.js` — loader, reveals, cursor, magnetic interactions, parallax and project tilt
- `assets/favicon.svg` — favicon
- `netlify.toml` — Netlify publish configuration

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- `https://github.com/YOUR_GITHUB`
- `https://www.linkedin.com/in/YOUR_LINKEDIN/`

Also replace or expand the project descriptions once the final project case studies/screenshots are ready.

## GitHub Pages

GitHub Pages can publish a static HTML/CSS/JavaScript site directly from a GitHub repository.

Recommended repository for a personal site:
`YOUR-GITHUB-USERNAME.github.io`

Then enable Pages from the repository settings and publish from the `main` branch.

## Netlify

Create a Netlify project and import the same GitHub repository. Because this is a static site, the publish directory is the repository root (`.`) and no build command is required.

Once GitHub and Netlify are connected, pushing changes to the production branch can trigger a new Netlify deployment automatically.

## Design direction

The portfolio intentionally uses:
- oversized editorial typography
- acid-green accent
- dark monochrome surfaces
- animated grid/orb background
- custom cursor
- magnetic buttons
- project tilt interactions
- scroll-triggered reveals
- loading sequence
- marquee typography
- responsive mobile layout
- reduced-motion support

No external JavaScript framework is required.
